### Check out: submit each chosen draft to its seller

<span className="nh-method nh-method--post">POST</span> `/v1/basket/checkout`

Each draft is submitted on its own, as P2 submission: prices checked again, your purchase limit, the seller’s acceptance. One seller refusing (a price that moved, a payment way it no longer takes) leaves that draft open and reports why; the others go ahead. Nothing is shared between the orders: each has its own acceptance, payment, shipments and invoices. A payment way per order, and a delivery address for all, are optional.

**Who can call it:** People and API clients · **Scope:** `cart:manage` · **Idempotency-Key:** required
