<span className="nh-method nh-method--post">POST</span> `/v1/orders/{id}/returns`

Each line names base units already shipped and not already being returned. Serial-tracked units may be named now (from those shipped on this order); the seller names them when they arrive at the latest. The seller authorises or rejects it.
