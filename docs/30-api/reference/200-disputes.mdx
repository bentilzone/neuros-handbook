### Seller: decide the dispute

<span className="nh-method nh-method--post">POST</span> `/v1/disputes/{id}/decide`

credit: a credit note for the amount (up to the disputed value; the disputed value if left out), across the order’s invoices; on an escrow order that much is refunded from escrow. replace: the disputed quantities are reserved again and shipped at no charge (refused if stock is short). return: a return is authorised for the disputed lines; its credit follows when it closes. reject: nothing changes. The reason is shown to the buyer. Whatever the dispute held on the escrow is then released if the buyer had already released the rest.
