### Two-step verification

With only a password, anyone who learns it can sign in as you. Two-step verification asks for a code from your phone as well. {props.who === 'operator' ? 'Platform staff must use it: the console reaches every company, so a password alone is not enough to sign in to it.' : 'Neuros requires it before you can approve money movements or change who may do what: invite members, edit roles, create API clients, change posting rules, close periods.'}

1. **Turn on**, then scan the QR code with Google Authenticator, 1Password or Authy. Can't scan? Enter the key shown instead.
2. Enter the 6-digit code it shows.
3. Save the **recovery codes**. Each signs you in once if you lose your phone, and they are not shown again.
4. Sign out and back in with your code. Actions that need two-step verification check that this session began with it.

To turn it off, confirm with your password and a current code.

### Sessions

**Signed-in devices** lists where you are signed in. **Sign out everywhere** ends every session on every device, this one included. Use it if a device is lost.
