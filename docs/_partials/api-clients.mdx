## The secret

Neuros shows the **client ID** and **client secret** once, right after you create the client. Store the secret in your system's secret manager before pressing **I have saved it**. If it is lost, rotate to issue a new one.

| Action | What happens |
|---|---|
| Edit scopes | The client's next call uses the new scopes |
| Rotate secret | The current secret stops working immediately. Update your system with the new one |
| Revoke | Every call with this client fails from now on. This cannot be undone |

Each client's calls appear under **API requests** in the <PageLink who={props.who} page="audit-log">audit log</PageLink>. Your plan limits how many clients you can have.
