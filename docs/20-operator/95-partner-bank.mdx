The [partner bank](../01-glossary/47-partner-bank.mdx#partner-bank) holds every seller’s escrow and opens their customers’ virtual accounts. Here you name the partner and set the [platform fee](../01-glossary/47-partner-bank.mdx#platform-fee) taken from each escrow release. Saving needs `platform:fees:manage` and a session signed in with two-step verification; every change is in the audit log.

**Bank’s webhook** shows whether the server has the secret the bank signs its reports with. It is set with the deployment, never on this page. While it is missing, the bank’s reports are refused, so no payment reaches a seller’s **Collections**.
