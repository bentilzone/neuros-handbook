The background jobs that renew subscriptions, send reminders, recognise revenue and purge old records. Each row shows how often it runs, its last run and how it went, its next run, and its failures in the last 24 hours. Click a job for its runs over the last 30 days.

<Shot id="operator/schedulers/list" />

| Action | What it does |
|---|---|
| **Run now** | Runs it once now and waits for it. It shares the schedule's lease, so it never runs twice at once. |
| **Pause** / **Resume** | Skips its scheduled runs until resumed. Running it by hand still works. |
| **Change schedule** | Sets how often it runs. |

Each asks for a reason, kept in the audit log. Running, pausing and rescheduling need a session signed in with two-step verification.
